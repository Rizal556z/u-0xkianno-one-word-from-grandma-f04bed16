## What the program does

`main.py` (pure Python standard library, no network, no model calls)
writes exactly one word to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`).

## The word

**Al** — Grandma heard "AI" and decided it must be a nice young man
named Al who lives inside the computer and helps with things. She
texts him like an old friend: "Tell Al I said hello."

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/grandma-test python3 main.py
cat /tmp/grandma-test/entry.txt  # Al
```
